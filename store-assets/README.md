# Store assets

Chrome Web Store listing materials for **RadioX**.

| File | Use |
|------|-----|
| `LISTING.md` | Title, description, permission justifications |
| `real-1-home.jpg` … `real-5-countries.jpg` | Store screenshots (canonical) |
| `marquee-1400x560.*` | Small promo tile / marquee |
| `promo-small-440x280.*` | Small promo tile |
| `store-icon-128.png` | Store icon |
| `x-launch*.png` | Social launch creatives |

Rebuild the upload zip locally after `npm run build` — do not commit `.zip` packages.
