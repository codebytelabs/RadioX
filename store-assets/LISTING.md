## Description
RadioX is a premium, ad-free internet radio player for Chrome.

Discover thousands of stations worldwide with curated featured shelves, popular and trending charts, genre and country browsing, favorites, and recently played. Keep listening while you browse with reliable background playback.

Built-in tools:
• 10-band equalizer
• Sleep timer
• Now-playing track log (Find Song + CSV export for supporters)
• Media keys support

No ads. No analytics trackers. Tips via Buy Me a Coffee or Ko-fi are optional and unlock unlimited track history.

## Permission justifications
- storage: Save favorites, recent stations, EQ, sleep timer, and supporter unlock locally.
- offscreen: Play audio from the service worker (MV3 requirement).
- notifications: Optional now-playing notifications.
- alarms: Sleep timer / scheduled stop.
- Host permissions (http/https): Connect to Radio Browser directory and to arbitrary station stream URLs worldwide. RadioX only requests streams the user chooses to play.
